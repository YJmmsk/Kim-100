# 김옥년 여사 백수연 웹 초대장

정적 HTML 초대장입니다. GitHub Pages(main 브랜치, 루트 폴더)로 배포합니다.

## 문구·사진 수정
- 문구: `index.html`에서 해당 문장을 고친 뒤 커밋하면 1~2분 뒤 반영됩니다.
- 사진: `images/` 폴더의 같은 이름 파일을 교체합니다(cover.jpg/webp, og.jpg, map.png/webp).
